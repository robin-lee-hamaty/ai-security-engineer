# About *AI Security Engineer*

*AI Security Engineer* is an independent, free educational book on the security of modern AI systems. It was written and designed by **Robin Lee Hamaty** as a single, continuous path from a complete beginner's foundations to professional, managerial, and research-level practice.

## Why it exists

Good AI security knowledge is scattered across papers, blog posts, framework documents, and expensive courses. This book gathers it into one ordered curriculum that a motivated learner can follow end to end, and makes the ideas concrete with runnable code, defensive demonstrations, hands-on labs, assessments, and case studies.

The goal is access: security knowledge should not depend entirely on someone's ability to afford expensive training.

## What it is — and is not

- It **is** an independent educational work, released free of charge under an open license.
- It **is** built to be executed, broken, defended, and taught.
- It is **not** an accredited qualification or university degree.
- It has **not** been peer reviewed.
- It is **not** published by a university or standards body.

## How to use it

Work top to bottom if you are starting out, or jump to any topic if you are revising. Run the code. Break it. Defend it. Then explain it to someone else. Every concept is meant to be practiced, not just read.

Security examples are for defensive learning and authorized testing only — see [`../SECURITY.md`](../SECURITY.md).

## Author

**Robin Lee Hamaty** is a security engineer and offensive-security specialist with over two decades of hands-on experience across information technology and cyber security, and the founder of White Rabbit, his independent security practice.
