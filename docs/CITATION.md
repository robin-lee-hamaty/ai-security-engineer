# How to cite

Please cite the permanent Zenodo record so links remain stable across versions.

## APA

> Hamaty, R. L. (2026). *AI Security Engineer: A University-Grade Guide from Beginner to PhD* (Version 1.0). Zenodo. https://doi.org/10.5281/zenodo.PENDING

## IEEE

> R. L. Hamaty, *AI Security Engineer: A University-Grade Guide from Beginner to PhD*, Version 1.0. Zenodo, 2026. doi: 10.5281/zenodo.PENDING

## BibTeX

```bibtex
@book{hamaty2026aisecurityengineer,
  title     = {AI Security Engineer: A University-Grade Guide from Beginner to PhD},
  author    = {Hamaty, Robin Lee},
  year      = {2026},
  version   = {1.0},
  publisher = {Zenodo},
  doi       = {10.5281/zenodo.PENDING},
  url       = {https://doi.org/10.5281/zenodo.PENDING}
}
```

A machine-readable citation is also provided in [`../CITATION.cff`](../CITATION.cff).

> The DOI shown as `PENDING` is replaced with the real Zenodo DOI on publication.
