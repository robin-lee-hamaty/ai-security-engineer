## About the book

*AI Security Engineer* is a single, continuous learning path for the security of modern AI systems. Rather than a loose collection of articles, it builds understanding in order: it starts from first principles a beginner can follow, and progresses to the professional, managerial, and research-level judgment expected of a senior AI security engineer. Concepts are taught to be executed, broken, defended, and explained, with runnable examples, defensive demonstrations, hands-on labs, assessments, and case studies throughout.

It is an **independent educational work**. It is not an accredited qualification, it has not been peer reviewed, and it is not published by a university.

## Hands-on learning

The book is built to be run, not just read. It contains runnable code examples, defensive demonstrations, a deliberately vulnerable practice lab, graded assessments with answer keys, a case-study library, and a master glossary. Security examples are for defensive learning and must only be executed against systems you own or are explicitly authorized to test.
