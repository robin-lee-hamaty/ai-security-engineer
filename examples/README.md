# Examples

The book is the canonical source of all code. It contains runnable examples, defensive demonstrations, hands-on labs, assessments, and case studies, each shown with its real output.

This folder is a home for **original, standalone code samples** that are extracted from the book accurately and can be run on their own. Any file added here:

- is licensed under the [MIT License](../LICENSE-CODE) (unlike the book text, which is CC BY 4.0);
- must be defensive and educational;
- must run and produce the output it claims;
- must only be used against systems you own or are explicitly authorized to test.

If you would like a specific example turned into a standalone, tested file here, open an issue or pull request (see [`../CONTRIBUTING.md`](../CONTRIBUTING.md)). Examples are added deliberately and verified, rather than bulk-dumped, so that everything in this folder actually runs.
